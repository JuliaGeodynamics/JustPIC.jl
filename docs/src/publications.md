# Publications

Papers that use JustPIC.jl, newest first. The list is kept up to date by a publication bot (`_pubbot` in the repository), which scans [OpenAlex](https://openalex.org) twice a month for papers that name the package and proposes them in a pull request. If your paper is missing, open an issue with its DOI ("Add a publication").
